[HUD] Disable Components — reference sheet
==========================================

Documentation only. The mod does NOT read this file at runtime.

  * Defaults live in  Lua/Shared/FeatureRegistry.lua
  * Live server state persists to  <SaveFolder>/ModConfigs/HUDDisableComponents.json

Every setting defaults to the value that changes nothing, so installing
the mod is a no-op until an admin turns something on.


Settings list (the in-game menu, in order)
------------------------------------------
  HideHealthBars       1   HP bars above characters
  HidePlayerNames      2   Names above characters, in the health scanner, in the health menu
  HideSkillXpPopups    3   Skill-up and experience-gain popups
  HideChatBubbles      4   Speech bubble carrying a typed chat message
  HideVoiceBubbles     5   Voice-chat bubble above other characters
  HidePrivilegeIcon    6   Host/permission icon in the tab player list
  HideItemHighlights   7   Selection outline on interactable items
  LockHealthMenu       8   Makes the health menu non-interactive
  LockAltOverlay       9   Alt-held name/tooltip highlight overlay
  HideUpperHud        10   Crew status panel + respawn/round-end timers
  DisableGiveIn       11   Makes the "Give In" button non-functional
  HideChatNameLink    12   Clickable player-profile link on chat names
  HideQuickMarkIcons  15   Fire/breach/etc. icons beside chat (messages stay)
  MuteChatGlobal      16   Blocks chat for every player

  LockCameraZoom           Forces every client to the zoom level below
  CameraZoomLevel          Numeric, 0.3 - 3.0, default 1.0
  DisableCameraFollow      Turns off camera drift toward the cursor


Opening the menus
-----------------
  Pause menu -> "[HUD] Disable Components"
  console:  hdc_menu       settings list
            hdc_console    remote console


Commands
--------
Client, affect only yourself:
  hdc_hideui           13   Toggle your own entire interface
  hdc_hidecursor       14   Toggle your own mouse cursor
  hdc_menu                  Open/close the settings list
  hdc_console               Open/close the remote console
  hdc_clientstate           Print the policy this client is applying

Server:
  hdc_serverstate           Print the authoritative policy
  hdc_resync                Re-send the policy to every client
  hdc_mute / hdc_unmute     Mute one player's chat
  hdc_mutelist              List muted players
  hdc_alive            10   Print who is alive
  hdc_console_allow <cmd|*> Whitelist a remote command ('*' allows everything)
  hdc_console_list          Show the remote-console whitelist
  hdc_integrity             Which clients answer the mod probe
  hdc_integrity_autokick    Toggle kicking clients that stop answering

Chat:
  !alive               10   Who is still alive. Spectators, dead players, admins only.


Remote console
--------------
Admin picks a player, types a command, it runs on that player's client;
their console output streams back into the window. Useful for the vanilla
`hideupperhud` and similar commands, which are more update-proof than
patching the HUD directly.

Commands are checked against a whitelist before being forwarded, so the
feature stays "drive the HUD on a client" rather than "run anything on a
player's machine". Defaults: hideupperhud, togglehud, toggleupperhud,
zoom, followcursor, and this mod's own hdc_* client commands. Extend with
hdc_console_allow. `hdc_console_allow *` removes the whitelist entirely —
that hands anyone with hudRemoteConsole full client-command access to
every player.

Every accepted command is written to the server log with who sent it and
to whom, whether or not an admin window is open.


Permissions — two SEPARATE capabilities
---------------------------------------
  hudDisableComponents   may change the synced HUD policy
  hudRemoteConsole       may run commands on other players' clients

Both are assigned per client under Manage Permissions -> Console Commands.
The server owner has both.

Granting the first does NOT grant the second. Driving someone else's game
client is a much larger capability than toggling HUD elements, so it is
handed out and checked separately.

hudDisableComponents also accepts the built-in ManageSettings permission.
hudRemoteConsole deliberately does not — it must be ticked explicitly.


Security model — read before changing the permission code
---------------------------------------------------------
Authorization is enforced on every inbound network message, never by
hiding UI. Every client downloads the whole mod including the admin UI
source, so "they do not have the menu" is not a state that can be created
or verified. A player without permission may open any window here; the
server simply refuses to act on what they send.

WHAT THIS DOES NOT DO: a client running patched Lua can ignore the
client-side HUD restrictions and can lie in the console mirror. That code
runs on their machine. The integrity probe (hdc_integrity) catches the
realistic cases — mod missing, disabled, crashed, or version-mismatched —
and can auto-kick. It cannot stop a determined spoofer.

Treat the console mirror as an audit trail and the probe as detection.
Anything that must be guaranteed has to be enforced server-side, the way
the chat mute is: messages from muted players are dropped on the server
before broadcast, so a modified client cannot undo it.


Design note
-----------
Item 10 hides the crew panel by suppressing its rendering only. The mod
never removes anyone from the real crew or client list. Mods that do that
break bot commands, break player selection in the tab menu, and make the
round-end screen report a team wipe after a successful mission. Because
the list stays intact here, !alive reports the truth and none of those
problems arise.
